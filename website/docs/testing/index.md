# Testing

<Lead>Billpay's tests split into two tracks. **Functional** tests (unit, integration, replay, and E2E) prove the platform does the right thing. **Non-functional** tests prove it performs.</Lead>

- [Functional](./functional/index.md) covers unit, integration, replay, and E2E tests.
- [Non-Functional](./non-functional/index.md) covers performance testing.
