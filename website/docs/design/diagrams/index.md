# Diagrams

<Lead>Two visual cuts through the same platform: the states a payment moves through, and the calls that move it.</Lead>

- [State Diagrams](./state-diagram.md) take the lifecycle apart one workflow at a time: the states each workflow drives and where it hands off to the next.
- [Sequence Diagrams](./sequence-diagram.md) trace all twelve flows end to end, from caller to core API to router to workflow to the activity groups that do the work.

The single big-picture view, every state and transition on one canvas with Consumer and Corporate side by side, lives on the [Payment State Model](../payment-state-model.md) page.
